# Firawynix Workspace Store listing draft

## Português (Brasil)

**Descrição curta:** Monitor de serviços Linux, IDE com IA local e comparação
de arquivos em um aplicativo Windows.

**Descrição:** Firawynix Workspace reúne três ferramentas em um aplicativo
para Windows. Acompanhe serviços Linux nos servidores que você configurar no
Monitor. Desenvolva projetos na IDE com editor, terminal e recursos opcionais
de IA local. Compare arquivos e pastas no FirawMerge e revise alterações antes
de salvar um resultado.

O Monitor começa sem servidores cadastrados. As comparações locais não exigem
uma conexão com o Monitor. Recursos de rede, como SSH, pesquisa web e download
de modelos, dependem da sua configuração ou de uma ação sua.

**Recursos em destaque:**

- Monitor de serviços Linux por conexões SSH configuradas pelo usuário.
- IDE com interface em português brasileiro e inglês, editor e terminal.
- Seleção e instalação opcionais de modelos para IA local.
- Comparação de arquivos e pastas e revisão de mudanças com FirawMerge.

**Requisitos:** Windows 10 ou 11, arquitetura x64. Conexão de rede somente
para recursos que dependem dela. Modelos de IA exigem espaço adicional em
disco e hardware compatível.

## English (United States)

**Short description:** Linux service monitoring, a local AI IDE, and file
comparison in one Windows app.

**Description:** Firawynix Workspace brings three tools together in one
Windows app. Monitor Linux services on servers you configure in Monitor. Work
on projects in the IDE with an editor, terminal, and optional local AI tools.
Compare files and folders in FirawMerge and review changes before saving a
result.

Monitor starts without configured servers. Local comparisons do not require a
Monitor connection. Network features such as SSH, web search, and model
downloads depend on your configuration or an action you take.

**Key features:**

- Linux service monitoring over SSH connections configured by the user.
- IDE interface in Brazilian Portuguese and English, with editor and terminal.
- Optional selection and installation of local AI models.
- File and folder comparison and change review with FirawMerge.

**Requirements:** Windows 10 or 11, x64. A network connection is needed only
for features that use it. AI models need additional disk space and compatible
hardware.
